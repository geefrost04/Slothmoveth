# ความรู้ความสามารถทั่วไป Set 2 - Authoring Blueprint

## Scope

- Product: Set 2: ข้อสอบแยกหมวด
- Delivery: 140 questions in 6 independently selectable categories
- Set 1 relationship: preserve coverage and learner journey; do not reuse prompts, numbers, distractors, media, or answer explanations
- Difficulty: 40% medium, 40% hard, 20% easy
- Commerce recommendation: one product covering all six categories, not six separate purchases
- Proposed price: THB 49 for the complete 140-question Set 2

## Content Gates Before Publishing

1. Every question has four distinct options, one provably correct answer, an explanation, and a concise solving tip.
2. No exact prompt, option set, diagram asset, or answer rationale overlaps Set 1 or an existing Mock Test.
3. Each category has a 20-30% visual/question-diagram target where a diagram improves the test rather than decorates it.
4. Answer keys are balanced within each category and across the 140 questions.
5. Arithmetic and formal-logic questions receive a deterministic calculation check before import.
6. Set 2 stays unpublished until an audit passes and the full product entitlement is verified.
